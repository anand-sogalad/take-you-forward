## What is a computer?

    - A computer is a machine that follows the instructions

## What is the difference between hardware and software?

    - A software is a set of instructions used to run instructions
    - A hardware is a physical device that runs the software

## What does the CPU do? What does RAM do? What does Storage do?

    - RAM is temporary and fast memroy that stores a program that is currently running
    - A storage is perment memory that holds software and other files
