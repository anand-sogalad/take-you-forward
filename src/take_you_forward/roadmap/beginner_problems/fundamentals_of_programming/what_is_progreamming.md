# What is programming?

## What is Computer?

A computer is a machine that processes instructions and data
to be precise, it takes input from user as instruction and executes the instruction and provides the output in the specified format

## Hardware vs Software

Hardware is physical component that can be touched

- CD
- Hard drive
- RAM
- CPU
- Keyboard
- Mouse
- Monitor

Sowatware is a programm or instruction that runs on the hardware to achieve something

- Operating System
- Driver
- Windows
- MacOs

Without Software, Hardware does nothing
Without Hardware, Software cannot run

So, both of them must exist

## CPU, RAM, STORAGE (Core components)

### CPU (Central Processing Unit)

- CPU is brain of an computer
- This process and executes instructions
- Facter the CPU, faster the process
- Faster the process, faster the execution

### RAM (Random Access Memory)

- This is temporary memory
- WHich means memory gets cleared when Machine powered off
- This is mainly used to load the running application

### Storage (Permnent Memory)

- This is permnent memory
- used to store the application
- used to store data in database, files etc..
- Which means data remains even when powered off

### How all together work

- When applicatio installed, it stored in Permanent memory (Storage)
- All of its applicaton data stored in Permanent memory (Storage)
- When Application opened, it will be loaded on Random Access Memory (RAM)
- And all of the instructions from application processed and execured by the CPU
